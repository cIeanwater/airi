# Humanning 项目概览

Humanning 是基于 [moeru-ai/AIRI](https://github.com/moeru-ai/airi) 的本地记忆与语音交互实验项目。
本仓库保留 AIRI 的应用框架和角色舞台，改进长期记忆、对话存储、模型调试与语音互动。

本文记录 2026-10-18 的项目边界。运行参数与具体验收结果以对应服务文档为准。

## 对话链路

```text
麦克风
  → 本地语音活动检测与回合判断
  → 转写与用户消息
  → 角色提示 + 当前会话 + 已授权的记忆证据
  → 本地 Gemma 4 E2B QAT INT4，流式生成
  → 助手消息保存
  → 语音合成与播放 + 情绪、动作与口型
```

当前 Gemma 接入处理文本，没有启用原生音频输入。
转写、回合判断、文本生成和语音合成是可分别替换的服务边界。
当前本机采用约 60 MB 的中英双语流式 Zipformer、Smart Turn v3.2 与 GPT-SoVITS v2ProPlus，默认 `student-bright`。
转写与停顿判断使用 CPU，Gemma 与 FP16 语音合成核心使用 GPU。转写后改写默认关闭，合成音频逐块播放。
说话打断使用持续语音确认，取消生成、合成和排队播放。
语音参考控制音色和部分韵律，ACT 控制人物表情。音尾判断与转写仍存在误判。
配置、实测和取舍见[学生声线研究](research/2026-10-18-compact-student-voice.zh-CN.md)。

## 三类记录

| 数据 | 目的 | 管理入口 |
| --- | --- | --- |
| 聊天记录 | 保留完整会话，备份、恢复与后续数据整理 | 设置 → 数据 → 聊天记录 |
| 长期记忆 | 从其他会话检索相关证据 | 设置 → 模块 → 长期记忆 |
| 模型请求 JSON | 查看一次模型调用的真实输入与输出 | 消息菜单 → 查看完整上下文，或本地服务记录目录 |

聊天记录默认持久化。长期记忆按用户和角色单独授权，默认关闭。
模型请求 JSON 只覆盖开启记录后经过本地服务的请求。
这些记录的生命周期不同，删除其中一类不等于删除全部副本。

## 改动与证据

| 方向 | 实现边界 | 证据 |
| --- | --- | --- |
| INT4 本地模型 | 官方 QAT Q4_0 权重，固定哈希，16K Q8 KV 缓存 | [运行说明](local-gemma4-int4.zh-CN.md) |
| 检索式长期记忆 | 本地 MiniSearch，用户和角色隔离，原文证据与来源 | [模块与评测](../../packages/memory-local/benchmarks/README.md) |
| 持久化回执 | 助手保存完成后才报告成功，导出等待保存队列 | [持久化 ADR](adr/2026-10-16-local-chat-persistence.zh-CN.md) |
| 离线 VAD | 模型与匹配运行库随应用打包，冷缓存时不依赖外网 | [离线验收](validation/2026-10-17-offline-voice-detection.zh-CN.md) |
| 角色互动 | 按实际动作组生成提示，处理有效动作与表情，随音频变化口型 | [联动验收](validation/2026-10-17-voice-expression-link.zh-CN.md) |
| 上下文调试 | 消息 ID 关联真实请求与输出，人格与记忆规则可直接编辑 | [修改入口](companion-context-editing.zh-CN.md) |

记忆评测包含 500 道 LongMemEval-S 问题，其中 470 道参与可回答问题的证据召回评分。
应用预算结果为六个证据块下 79.61% 会话召回率、60.00% 轮次召回率。
评测不包含生成回答准确率、中文检索质量或真实语音体验的主观评分。

## 部署边界

当前验证重点是 Windows 本地桌面环境。
已准备的本机环境可双击 `Start-Humanning.cmd` 启动。默认本地模式关闭登录、账号同步和官方托管服务。
源码继续包含上游的浏览器与移动端应用，但本仓库的本地服务验收不代表全平台验收。

模型权重与运行环境单独准备，真实消息与浏览器配置保存在 Git 仓库之外。
本地存储没有应用层加密。使用远程模型时，传入上下文仍会到达相应 Provider。

当前未提供单独验收的 Humanning 安装包。上游 AIRI 的演示与安装包描述上游版本。
本文不改变包名、应用 ID、原作者元数据或第三方资产许可。
